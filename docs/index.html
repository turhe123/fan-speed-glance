Features

Read-only, and quietly useful.

A narrow monitor that shows what your fans are doing and warns you only when something looks wrong.

Live RPM in the menu bar

Show the highest fan RPM, a fan glyph, or both. Values round to the nearest 10 and use fixed-width digits so the status item stays steady.

Every fan, with context

The popover lists each fan with its current RPM, percent of maximum, a gauge, and its minimum and maximum speed. Two-fan Macs show Left and Right.

Ten-minute sparkline

A short rolling history for each fan makes spin-ups easy to spot. It is kept in memory only and never written to disk.

Quiet or loud alerts

Get warned when a fan stays above your chosen percent of its maximum for over two minutes, or reads 0 RPM for a minute while the system is running warm. Notifications are off by default, with an optional sound.

Read-only by design

It never writes fan speeds, installs no helper tool and needs no root access. Fanless Macs like the MacBook Air show the thermal state instead.

Light on resources

Refresh every 1, 2 or 5 seconds. Polling pauses when the popover is closed and nothing else needs live data. Launch at login is optional.

Install

Up and running in a minute.

FanSpeedGlance is open source and not notarized with a paid Apple Developer ID, so macOS needs one extra step the first time.

  1. Download FanSpeedGlance-macOS.zip and unzip it.
  2. Move FanSpeedGlance.app to your Applications folder.
  3. Clear the quarantine flag once, then right-click the app and choose Open:
    xattr -cr /Applications/FanSpeedGlance.app
  4. No special permissions are required if you turn on alerts, allow notifications for FanSpeedGlance when macOS asks (System Settings Notifications).

FAQ

Questions, answered.

Is FanSpeedGlance really free and open source?

Yes. It is released under the MIT license, has no ads, no accounts and no paid tier. The full source is on GitHub, and if you find it useful you can support development through the Ko-fi button in the app.

What permissions does it need?

None to read fan speeds, which uses read-only calls to the AppleSMC service. Notification permission is requested only if you enable alerts, and a login item is added only if you enable Launch at login. It never asks for Accessibility, Screen Recording or Microphone access.

Where is my data stored?

Your settings are stored locally in the app's standard preferences. The ten-minute fan history lives in memory only and disappears when you quit. The app talks to no server.

Why isn't the app notarized?

Notarization requires a paid Apple Developer account, and this is a free project. Right-click the app and choose Open once to approve it, or build it yourself from source with Xcode.

Was this written by AI?

Yes. FanSpeedGlance was generated by Claude Code from a written spec as a clean-room reimplementation, with no code or assets from any commercial app. The full source is on GitHub under MIT, so you can read every line before you run it. It has had less human review than a hand-written app, so bug reports are welcome.
